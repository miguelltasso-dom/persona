# @deepseek-ai/dsh-client-ui-persona

Browser half of Persona, mounted as one client plugin with internal domains (theme, shell, chat, team, board, files, routines, usage, connections, onboarding, import, canvas). UI copy is Brazilian Portuguese through typed dictionaries.

Part of the Persona product group (`packages/persona/*`). See `persona-spec/PLAN.md` and `persona-spec/DECISIONS.md` (D-002, D-026).
