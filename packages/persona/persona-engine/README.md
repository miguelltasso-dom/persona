# @deepseek-ai/dsh-persona-engine

Native port of the MIT `dsh-superagent-prototype` engine: synchronous commands, one transaction per command, effects after commit. Defines the repository ports; `persona-store` implements them.

Part of the Persona product group (`packages/persona/*`). See `persona-spec/PLAN.md` and `persona-spec/DECISIONS.md` (D-002, D-026).
