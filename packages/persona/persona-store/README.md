# @deepseek-ai/dsh-persona-store

Owns `persona.db` through `node:sqlite`: monotonic `user_version`, `application_id` `PNSQ` (`0x504E5351`), WAL, `busy_timeout`, `STRICT` tables, `VACUUM INTO` backup before each adjacent immutable migration, and synchronous `tx()` (nested via savepoints; never `await` inside).

Open with `openPersonaStore({ path })`. Default on-disk layout is `<PERSONA_HOME>/db/persona.db` with backups in `<PERSONA_HOME>/db/backups/` (D-007, D-008). `backupNow()` writes an on-demand `VACUUM INTO` copy; `wipeWorkspace` / `wipeProject` delete tenant rows (personal project stays). Tests use `openTempStore` / `withTempStore`.

Schema v13 indexes Cofre uploads into `vault_chunk` + FTS (PDF/DOCX/MD/TXT/CSV, local extract). v14 is WAVE2: conversation topics, provider accounts + policy, teach artifacts. v15 is Segundo cérebro (`BrainRepos`): markdown pages as source, derived FTS/type/link index, immutable versions, remembered grants (exact scope, revoke, use). v16 is Gestor de equipe (`GestorRepos`): mandate limits, open plans by scope, audit (`team_manager_*`). v17 is token-opt (`OptRepos`): resumo incremental por assunto, cursores de lote (Bibliotecário/iniciativa), pool de limites por provedor. v18 is the per-turn ledger (`TurnLedgerRepos`): canonical `TurnKind` (`execution` / `evaluation`, never Rivet `exec`/`eval`), cache read/write, six context layers. v19 keys official quota by account (`usage_quota` PK `project_id+provider+account_id`) so the Lumen pool can keep one row per connected login and a short next-refill history in the body. v1 covers product entities (workspace, member, project including the built-in **Pessoal** kind, persona, participation, channel, dm), the per-stream event log + FTS5, the company vault + document FTS5, and routines (`RoutineRepos`: idempotency `routine_id:scheduled_for`, lease, catch-up, silence, pause-team). v8 adds per-project workflow, columns, fields, sprints, and ticket seats (`SqliteBoardRepos`). v10 is the persona card (speak/charge). v11 is workspace governance (`SqliteGovernanceRepos`: sector, away window, routine owner, audit; `snapshot` / `restore` for export/sync). Tenant boundary is `project_id` (D-038); governance rows are workspace-level (DM does not sync).

Part of the Persona product group (`packages/persona/*`). See `persona-spec/PLAN.md` and `persona-spec/DECISIONS.md` (D-002, D-007, D-008, D-021, D-026).
