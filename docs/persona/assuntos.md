# Assuntos coloridos

Cada canal e cada conversa direta tem **assuntos**: bolinhas com cor e nome no topo (nunca só a cor). O padrão é **Geral**. Você cria até sete (UI, Financeiro, …).

A mensagem nova vai para o assunto ativo. A persona responde no mesmo. Cada assunto tem o próprio histórico — o contexto de um não entra no outro, salvo quando você cita o outro assunto.

Uma Tarefa criada ali guarda o vínculo. O cartão no quadro mostra a bolinha de origem.

Renomear, arquivar e mover mensagem ficam no menu do assunto. Busca também filtra por assunto.
