# Relatórios dos builders

Formato: o que ficou pronto, arquivos, comandos e saída verbatim, edições em código do upstream (1 linha cada), o que ficou de fora. Depois acrescente UMA linha no post-it "Persona · Status" e siga para a próxima tarefa.
