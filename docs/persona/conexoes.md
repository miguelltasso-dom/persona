# Conexões

Uma persona executa por um **runner**:

- CLI instalada no computador (Claude, Codex, Cursor, OpenCode), ou
- chave de API que você colou.

A Persona não cria conta nesses serviços por você. Se a CLI não aparece, veja [Solução de problemas](./solucao-de-problemas.md).

Chaves ficam no computador. Elas não entram em manifesto, prompt montado, exportação nem proposta de contratação.
