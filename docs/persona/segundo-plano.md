# Segundo plano e bandeja

A equipe fica ligada enquanto o app está aberto.

**Bandeja.** Minimize para a bandeja. Pause a equipe se quiser silêncio. Sair encerra o anfitrião.

**Notificações.** A Persona avisa só o que precisa de você: pergunta, bloqueio, revisão pronta, cota no fim. Não manda um aviso por cada passo interno.

**Precisa de você.** Abra o cartão. Uma pergunta. Uma ação. Responda ali. A Tarefa retoma.

Se o host cair, abra o app de novo. As Tarefas abertas retomam. Nada some e nada duplica.
