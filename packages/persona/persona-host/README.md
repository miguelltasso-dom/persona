# @deepseek-ai/dsh-persona-host

Host plugin (`ctx.personaHost`) exposing the Persona domain to the UI through a Typert Remote controller (namespace `persona`). Remote v1: `ping`, lists (`listTeam`, `listPersonas`, `listProjects`, `listChannels`, `listDms`, `listTasks`, `getOverview`, `getOverviewNow`, `getWhileAway`), writes (`createWorkspace`, `createProject`, `updateProject`, `createMember`, `createPersona`, `addParticipation`, `removeParticipation`, `createChannel`, `createDm`, `postMessage`), `listMessages`, stream `followMessages` (baseline then upserts), `search` (ACL, no DM leak), project files (`listFiles`, `statFile`, `readFile`) confined to `project.rootPath`, routines (`createRoutine`, `listRoutines`, `pauseRoutine`, `pauseTeam`, `scheduleRoutine`, `claimRoutines`, `retryRoutine`), drafts (`draftPersona`, `draftTeam`), proactivity (`getAutonomy`, `setAutonomy`, `ensureInitiativeRoutines`, `fireProactiveEvent`, `tickProactivity`, `markVisit`), and Lumen screens (`issueInvite`, `listInvites`, `redeemInvite`, `revokeInvite`, `previewImport`, `confirmImport`, `getImportBatch`, `rollbackImport`, `listTriageRules`, `putTriageRule`, `deleteTriageRule`, `listQuietWindows`, `putQuietWindow`, `getProjectLimits`, `setProjectLimits`, `listApprovals`, `proposeHire`, `proposeVault`, `proposeSkill`, `decideApproval`, `listMemory`, `proposeMemory`, `approveMemory`, `editMemory`, `forgetMemory`, `listSkills`, `putSkill`, `reviseSkill`, `rollbackSkill`, `githubAvailable`, `ingestGithubWebhook`, `fetchGithubIssue`, `postGithubComment`). Peers without a role receive `no-allow`. Remote method rules: see `persona-spec/RECON.md` §5. After changing `@Remote` signatures run `pnpm exec tsx scripts/generate-typert.ts`. Public parameters must carry an explicit type (Typert gate).

Part of the Persona product group (`packages/persona/*`). See `persona-spec/PLAN.md` and `persona-spec/DECISIONS.md` (D-002, D-026).
